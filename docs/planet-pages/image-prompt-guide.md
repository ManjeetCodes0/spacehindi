# Image Prompt Writing Guide — Cinematic Space Visuals

## How to Write Image Prompts for Planet Pages

### Core Philosophy
Every image should look like it belongs in a **Hollywood space movie** (Interstellar, Gravity, The Martian, 2001: A Space Odyssey) or a **premium NASA visualization**. The goal is cinematic grandeur, scientific accuracy, and emotional impact.

### Prompt Structure (Follow This Order)

1. **Scene setup** — What is the main subject and camera angle?
2. **Key details** — What specific features are visible?
3. **Mood/atmosphere** — What emotion should it convey?
4. **Technical quality** — Lighting, camera style, render quality
5. **Color palette** — 4-5 specific colors that dominate
6. **Resolution tag** — Always end with "8K" or "8K cinematic render"

### Example Prompt Template
```
[Cinematic quality descriptor] [camera angle/perspective] of [main subject] 
[showing/featuring] [specific scientific details]. [Secondary elements in scene]. 
[Mood/atmosphere description]. [Lighting technique], [camera/film style]. 
Color palette: [color1], [color2], [color3], [color4]. 
8K, [quality reference].
```

### Quality Descriptors (Use These)
- "Ultra-realistic cinematic"
- "Breathtaking cinematic wide shot"
- "Hyper-dramatic cinematic visualization"
- "Stunning cinematic orbital view"
- "Epic cinematic"
- "Majestic cinematic digital painting"
- "Spectacular cinematic visualization"
- "Profoundly cinematic"
- "Atmospheric cinematic scene"
- "Mesmerizing cinematic cross-section"

### Camera/Perspective Options
- Full planet portrait from spacecraft flyby
- Low orbit view looking down at surface
- Ground-level surface view with planet/moon in sky
- Cross-section/cutaway visualization
- Interior atmospheric visualization
- Historical/period scene (for discovery sections)
- Spacecraft POV approaching/departing
- Artistic mythology blend (for cultural sections)

### Lighting Techniques to Reference
- Volumetric god-rays from distant Sun
- Dramatic rim lighting on planet edge
- Backlighting creating silhouettes
- Chiaroscuro (strong light/dark contrast)
- Subsurface scattering through atmosphere
- Electric/lightning illumination from within
- Warm candlelight for historical scenes
- Dolby Vision HDR

### Film/VFX References to Use
- "IMAX 70mm quality"
- "Hollywood VFX quality"
- "Interstellar/Gravity cinematography"
- "NASA Voyager-inspired composition"
- "Ridley Scott visual style"
- "Weta Digital/ILM standard"
- "Concept art quality"
- "Dolby Vision HDR"

### Color Palette Rules
- Always specify 4-5 colors
- Use specific color names (not just "blue" but "sapphire blue", "cobalt", "indigo")
- Include the planet's theme colors
- Always include one contrast color for visual interest
- Deep space black should usually be one of the colors

### What Makes a Great Prompt
1. **Specificity** — Don't say "a storm", say "an enormous oval-shaped anticyclonic storm system dark as an abyss"
2. **Scale references** — "Earth-sized", "thousands of kilometers wide", "8 kilometers upward"
3. **Emotional language** — "haunting", "bittersweet", "alien desolation", "cosmic capture"
4. **Scientific accuracy** — Real temperatures, distances, chemical compounds, mission names
5. **Cinematic composition** — Describe framing (fills bottom two-thirds, dominates the frame, small in frame)

### Image Specs
- **Resolution:** 1920x1080 or 2560x1440 (landscape)
- **Format:** .webp
- **Orientation:** Always landscape
- **Style:** Photorealistic for space scenes, artistic for mythology/cultural scenes

### Common Mistakes to Avoid
- Too generic ("a picture of Mars") — be hyper-specific
- No mood/emotion described
- Missing color palette
- No lighting description
- Forgetting to mention the quality/resolution
- Not connecting the image to the section's specific topic
- Using portrait orientation (always landscape for backgrounds)
